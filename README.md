# Yogesh Garg — Portfolio

A responsive, animated portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open dist/index.html in a browser, or run:

    python -m http.server 4173 --directory dist

Then open http://localhost:4173.

## Editing

- dist/index.html: content, project details, and contact links
- dist/style.css: layout, colors, typography, and animations
- dist/script.js: navigation, disclosures, scroll reveals, and interactive motion

No build step or package installation is needed. Fonts use Google Fonts with system fallbacks.
Animations respect reduced-motion preferences. Contact links open the visitor's email client.

The landing diagram uses Full Stack, Cloud, Databases, and CI/CD categories.
Project visuals are illustrative; the GitHub link leads to the supplied profile.
pytest is included in the toolkit.

Work remains local while the design is being refined.
